# บันทึกการแก้โจทย์

ไฟล์นี้ต้องเขียนโดยนักศึกษาด้วยคำพูดของตนเอง

ใช้ template นี้เฉพาะกับโจทย์ OJ ที่ถูกระบุว่าต้องส่ง learning log เท่านั้น

ห้ามให้ AI เขียนไฟล์นี้แทนคุณ AI อาจช่วยตรวจ grammar, formatting หรือความชัดเจนได้ หลังจากที่คุณเขียนเนื้อหาของตนเองแล้ว

ถ้าใช้ AI กับโจทย์ learning-log-required นี้ ต้องทำไฟล์ `ai_reflection.md` ด้วย

## 1. ข้อมูล OJ

หมายเลข/ชื่อโจทย์ OJ:

```text
OJ3360 - [LEARNING LOGS] หั่นขนมปัง
```

OJ submission ID ถ้ามีการส่งแล้ว:

```text

```

สถานะ OJ:

```text
Pass
```

เวลาที่ใช้คิดและทำโจทย์ด้วยตนเอง:

```text
1-3 hours
```

เลือกหนึ่งข้อ:

```text
0-15 minutes
15-30 minutes
30-60 minutes
1-3 hours
3-6 hours
6-24 hours
1-3 days
4-7 days
1-4 weeks
More than 4 weeks
```

วิธีนับเวลา:

- นับเฉพาะเวลาที่ตั้งใจทำโจทย์นี้ด้วยตนเองจริง ๆ
- เริ่มนับตั้งแต่ตอนที่อ่านโจทย์ครั้งแรก
- ไม่นับเวลาพัก กินข้าว เรียน นอน เวลาที่ทำโจทย์อื่น หรือเวลาที่ไม่ได้ทำโจทย์นี้
- ถ้าใช้ AI ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อน prompt แรกที่ถาม AI
- ถ้าถามเพื่อน TA หรือผู้สอน ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อนขอความช่วยเหลือครั้งแรก
- ถ้าใช้ทั้ง AI และความช่วยเหลือจากคน ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อนขอความช่วยเหลือจากภายนอกครั้งแรก ไม่ว่าจะเป็น AI หรือคน
- ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้นับเวลาถึงก่อนเขียน `submission.md`
- ประมาณเวลาได้ แต่ต้องซื่อสัตย์

## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
โจทย์ให้ฉันรับขนาดของขนมปังและข้อมูลของใบมีด จากนั้นให้หาว่าขนมปังชิ้นย่อยที่ถูกตัดด้วยมีดแนวตั้งและแนวนอนตามพิกัดที่ให้ ชิ้นที่พื้นที่มากที่สุดสองชิ้น จะมีพื้นที่เท่าใด

Input:
บรรทัดแรก: รับจำนวนเต็มทั้งหมดสี่จำนวน คือ w h m n (w คือ ความกว้างของขนมปัง, h คือ ความสูงของขนมปัง, m คือ จำนวนใบมีดแนวตั้ง, n คือ จำนวนใบมีดแนวนอน)
บรรทัดที่สอง: รับจำนวนเต็มทั้งหมด m จำนวน เพื่อระบุพิกัดแกน x คือ x1, x2, x3, ..., xm
บรรทัดที่สาม: รับจำนวนเต็มทั้งหมด n จำนวน เพื่อระบุพิกัดแกน y คือ y1, y2, y3, ..., yn

Output:
โปรแกรมแสดงผลลัพธ์จำนวนเต็มสองจำนวนที่เป็นชิ้นขนมปังตัดแล้วมีพื้นที่ของชิ้นที่ใหญ่ที่สุดและใหญ่เป็นอันดับสอง โดยพิมพ์จำนวนมากกว่าก่อน

Constraints:
Input เป็นจำนวนเต็ม, wและh มีค่าอยู่ระหว่าง 1-10000, mและn มีค่าอยู่ระหว่าง 1-1000,ตำแหน่งมีดแต่ละใบจะมากกว่า 0 แต่น้อยกว่า w หรือ น้อยกว่า h และเรียงจากน้อยไปมาก
```

## 3. แผนแรกของฉัน

เขียนแผนแรกก่อนรับความช่วยเหลือจาก AI เพื่อน TA ผู้สอน หรือก่อนสรุป code สุดท้าย

ถ้าใช้ AI ให้เขียนแผนที่มีอยู่ก่อน prompt แรกที่ถาม AI

ถ้าถามเพื่อน TA หรือผู้สอน ให้เขียนแผนที่มีอยู่ก่อนถาม

ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้เขียนแผนที่มีอยู่ก่อนหรือระหว่างเริ่มเขียน code

แผนนี้เขียนแบบคร่าว ๆ ได้ อาจยังไม่สมบูรณ์หรืออาจต่างจากวิธีสุดท้าย

สามารถเขียนเป็น pseudocode, flowchart idea หรือขั้นตอนความคิดได้

```text
Step 1:รับจำนวนเต็ม w h m n ในบรรทัดแรก รับตำแหน่งมีดแนวตั้งในบรรทัดที่สอง และรับตำแหน่งมีดแนวนอนใน บรรทัดที่สาม โดยจะรับตำแหน่งมีดทั้งแนวตั้งและแนวนอนเก็บไว้ใน list
Step 2:เติม 0 ที่ขอบล่างของมีดแนวนอนและแนวตั้ง ส่วนขอบบนของมีดแนวตั้งเติม w ส่วนมีดแนวนอนเติม h เป็นขอบบน
Step 3:ใช้ for loop เพื่อวนดูตำแหน่งใบมีดในแนวตั้ง m+1 รอบ(มีด m ใบจะแบ่งขนมปังได้ m + 1 ช่อง) จากนั้นนำตำแหน่งถัดไปลบกับตำแหน่งที่อยู่ปัจจุบัน จะได้ความกว้างของแต่ละช่อง แล้วเก็บไว้ใน list
Step 4: ทำมีดแนวนอนโดยใช้วิธีเดียวกับมีดแนวตั้ง แล้วเก็บไว้ใน list อีกตัว
Step 5: เรียง list ทั้งสองตัว จากมากไปน้อย
Step 6:หาพื้นที่มากสุดของขนมปังที่ตัดแล้ว จากการนำตัวแรก(เป็นตัวที่มากที่สุดเพราะได้ทำการเรียงจากมากไปน้อยแล้วใน Step 5)ของ list ทั้งสอง มาคูณกัน
Step 7:หาพื้นที่ขนมปังที่ใหญ่เป็นอันดับสองซึ่งมีสองวิธี 1.นำตัวแรกใน list 1 คูณกับตัวที่สองของ list 2 หรือ 2.นำตัวที่สองของ list 1 คูณกับ ตัวแรกของ list 2 จากนั้นใช้ max ในการเลือกค่าที่มากที่สุดออกมา
Step 8:แสดงผลลัพธ์เป็นแบบบรรทัดเดียว โดยมีพื้นที่ขนมปังที่มากที่สุด และ พื้นที่ขนมปังที่ใหญ่เป็นอันดับสอง
```

## 4. วิธีสุดท้ายที่ใช้จริง

อธิบายสั้น ๆ ว่า algorithm หรือวิธีสุดท้ายที่ใช้จริงใน code ที่ส่งคืออะไร

หัวข้อนี้ต่างจาก Section 3:

- Section 3 คือแผนแรกก่อนใช้ AI ก่อนรับความช่วยเหลือจากคน หรือก่อนเขียน code สุดท้าย
- Section 4 คือวิธีสุดท้ายที่ใช้ใน solution จริง
- ถ้าวิธีสุดท้ายเหมือนกับแผนแรก ให้เขียนว่าเหมือนกัน และอธิบายสั้น ๆ ว่าทำไม

ห้ามคัดลอกคำอธิบายจาก AI

ห้ามคัดลอกคำอธิบายจากคนอื่น

```text
วิธีสุดท้ายของฉันเหมือนกับแผนแรก ฉันรับจำนวนเต็ม w h m n มา และรับตำแหน่งของใบมีดทั้งแนวตั้งและแนวนอนมาเก็บไว้ใน list จากนั้นเติมขอบของมีดแนวตั้งโดยขอบล่างเป็น 0 และ ขอบบนเป็น w ส่วนขอบของมีดแนวนอน ขอบล่างเป็น 0 และขอบบนเป็น h (เพราะตำแหน่งมีดไม่รวมขอบขนมปัง ถ้าไม่เติมจะขาดช่องริมสุดทั้งสองด้าน) จากนั้นฉันใช้ for loop วนลูป m + 1 (ใบมีดแนวตั้ง) รอบแล้วนำตำแหน่งถัดไปลบกับตำแหน่งที่อยู่ปัจจุบัน จะได้ความกว้างของแต่ละช่อง แล้วเก็บไว้ใน list จากนั้นก็ทำของใบมีดแนวนอนเหมือนกัน แล้วนำค่าที่อยู่ใน list ทั้งสองมาเรียงจากมากไปน้อยโดยใช้ method .sort(reverse=True) และหาพื้นที่ขนมปังที่มากสุดด้วยการนำตัวแรกของทั้งสอง list มาคูณกัน แล้วหาขนมปังที่พื้นที่ใหญ่เป็นอันดับสองจากการนำตัวแรกของ list แรกคูณกับตัวที่สองของ list สอง หรือ ตัวที่สองของ list แรกคูณกับตัวแรกของ list สอง แล้วใช้ max เลือกค่าที่มากที่สุด จากนั้นแสดงผลลัพธ์ พื้นที่ขนมปังที่มากสุดกับพื้นที่ขนมปังที่ใหญ่เป็นอันดับสอง แบบบรรทัดเดียว
```

## 7. ความช่วยเหลือจากคน / การร่วมมือ

ได้ถามเพื่อน TA ผู้สอน หรือบุคคลอื่นเพื่อขอความช่วยเหลือในโจทย์นี้หรือไม่

```text

```

ถ้าใช่ ให้อธิบายสั้น ๆ ว่าได้รับความช่วยเหลือแบบใด

ตัวอย่างที่อนุญาต:

- อธิบายความหมายของโจทย์
- อธิบาย concept การเขียนโปรแกรม
- ให้ hint เกี่ยวกับแนวทาง
- คุยเรื่อง debugging
- คุยเรื่อง test cases
- ช่วยอธิบาย error message

สิ่งที่ไม่อนุญาต:

- คัดลอก code ของผู้อื่น
- ส่ง solution ของผู้อื่น
- ขอให้ผู้อื่นเขียน solution ให้
- ใช้ OJ submission ของผู้อื่น
- ขอให้ผู้อื่นส่ง OJ แทน
