# บันทึกการแก้โจทย์

ไฟล์นี้ต้องเขียนโดยนักศึกษาด้วยคำพูดของตนเอง

ใช้ template นี้เฉพาะกับโจทย์ OJ ที่ถูกระบุว่าต้องส่ง learning log เท่านั้น

ห้ามให้ AI เขียนไฟล์นี้แทนคุณ AI อาจช่วยตรวจ grammar, formatting หรือความชัดเจนได้ หลังจากที่คุณเขียนเนื้อหาของตนเองแล้ว

ถ้าใช้ AI กับโจทย์ learning-log-required นี้ ต้องทำไฟล์ `ai_reflection.md` ด้วย

## 1. ข้อมูล OJ

หมายเลข/ชื่อโจทย์ OJ:

```text
OJ3537 - [LEARNING LOGS] Impostor
```

OJ submission ID ถ้ามีการส่งแล้ว:

```text

```

สถานะ OJ:

```text
Pass
```

เวลาที่ใช้คิดและทำโจทย์ด้วยตนเอง:

```text
1-3 hours
```

เลือกหนึ่งข้อ:

```text
0-15 minutes
15-30 minutes
30-60 minutes
1-3 hours
3-6 hours
6-24 hours
1-3 days
4-7 days
1-4 weeks
More than 4 weeks
```

วิธีนับเวลา:

- นับเฉพาะเวลาที่ตั้งใจทำโจทย์นี้ด้วยตนเองจริง ๆ
- เริ่มนับตั้งแต่ตอนที่อ่านโจทย์ครั้งแรก
- ไม่นับเวลาพัก กินข้าว เรียน นอน เวลาที่ทำโจทย์อื่น หรือเวลาที่ไม่ได้ทำโจทย์นี้
- ถ้าใช้ AI ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อน prompt แรกที่ถาม AI
- ถ้าถามเพื่อน TA หรือผู้สอน ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อนขอความช่วยเหลือครั้งแรก
- ถ้าใช้ทั้ง AI และความช่วยเหลือจากคน ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อนขอความช่วยเหลือจากภายนอกครั้งแรก ไม่ว่าจะเป็น AI หรือคน
- ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้นับเวลาถึงก่อนเขียน `submission.md`
- ประมาณเวลาได้ แต่ต้องซื่อสัตย์

## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
โจทย์ให้ฉันรับชื่อและบทบาทของทุกคนและคนที่ถูกขับไล่ จากนั้นหาผู้ที่ยังอยู่ในยานอวกาศ และ ถูกขับไล่ไปแล้วเป็นชื่อตามด้วยบทบาท

Input:
โปรแกรมรับชื่อและบทบาท หลายบรรทัด จนกว่าจะเจอคำว่า "Start" จึงจะหยุดรับ
โปรแกรมรับชื่อผู้ที่ถูกโหวตออก หลายบรรทัด จนกว่าจะเจอคำว่า "End" จึงจะหยุดรับ

Output:
หลายบรรทัด
บรรทัดแรก: จำนวน Impostor ที่เหลืออยู่ตามด้วย "Impostor Remains"
บรรทัดต่อมา: "***Alive***"
บรรทัดต่อมา: รายชื่อผู้รอดชีวิตทุกคนตามด้วยบทบาทจนครบ
บรรทัดต่อมา: "***Dead***"
บรรทัดที่เหลือ: รายชื่อผู้เสียชีวิตตามด้วยบทบาท

Constraints:
output ของทั้งกลุ่ม "Alive" และ "Dead" เรียงตามตัวอักษรของชื่อผู้เล่น และโจทย์แนะนำให้ใช้ dict และ dict methods
```

## 3. แผนแรกของฉัน

เขียนแผนแรกก่อนรับความช่วยเหลือจาก AI เพื่อน TA ผู้สอน หรือก่อนสรุป code สุดท้าย

ถ้าใช้ AI ให้เขียนแผนที่มีอยู่ก่อน prompt แรกที่ถาม AI

ถ้าถามเพื่อน TA หรือผู้สอน ให้เขียนแผนที่มีอยู่ก่อนถาม

ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้เขียนแผนที่มีอยู่ก่อนหรือระหว่างเริ่มเขียน code

แผนนี้เขียนแบบคร่าว ๆ ได้ อาจยังไม่สมบูรณ์หรืออาจต่างจากวิธีสุดท้าย

สามารถเขียนเป็น pseudocode, flowchart idea หรือขั้นตอนความคิดได้

```text
Step 1: สร้าง dict ว่างไว้สองตัวแปร
Step 2: วนลูปรับข้อมูลทีละบรรทัด จนกว่าจะเจอคำว่า "Start" แล้วจึงหยุด
Step 3: ในแต่ละบรรทัด ตัดปีกกาและเครื่องหมายคำพูดออกแล้วแยกชื่อกับบทบาทด้วย ":" จากนั้นเก็บลงไว้ใน dict ที่สร้างไว้ตัวแรก โดยให้ชื่อเป็น key แล้วบทบาทเป็น value
Step 4: วนลูปรับชื่อผู้ที่ถูกโหวตออกทีละบรรทัด จนกว่าจะเจอคำว่า "End" แล้วจึงหยุด
Step 5: ในแต่ละบรรทัด ดึงชื่อออกจาก dict แรกที่สร้างไว้แล้วเก็บลงใน dict ตัวที่สองพร้อมบทบาท
Step 6: นับจำนวน Impostor ที่เหลือใน dict แรก โดยนับ value ที่เป็น "Impostor" แล้วพิมพ์ตามด้วย "Impostor Remains"
Step 7: พิมพ์ "***Alive***" แล้ววนลูปพิมพ์ชื่อและบทบาทของผู้ที่เหลือใน dict แรก โดยเรียงตามตัวอักษรชื่อ
Step 8: พิมพ์ "***Dead***" แล้ววนลูปพิมพ์ชื่อและบทบาทของผู้ที่อยู่ใน dict สอง โดยเรียงตามตัวอักษรชื่อ
```

## 4. วิธีสุดท้ายที่ใช้จริง

อธิบายสั้น ๆ ว่า algorithm หรือวิธีสุดท้ายที่ใช้จริงใน code ที่ส่งคืออะไร

หัวข้อนี้ต่างจาก Section 3:

- Section 3 คือแผนแรกก่อนใช้ AI ก่อนรับความช่วยเหลือจากคน หรือก่อนเขียน code สุดท้าย
- Section 4 คือวิธีสุดท้ายที่ใช้ใน solution จริง
- ถ้าวิธีสุดท้ายเหมือนกับแผนแรก ให้เขียนว่าเหมือนกัน และอธิบายสั้น ๆ ว่าทำไม

ห้ามคัดลอกคำอธิบายจาก AI

ห้ามคัดลอกคำอธิบายจากคนอื่น

```text
วิธีสุดท้ายของฉันเหมือนกับแผนแรก ฉันสร้าง dict ว่างขึ้นมาสองตัวชื่อว่า player และ out จากนั้นใช้ while วนรับข้อมูลทีละบรรทัด ถ้าเจอคำว่า "Start" ให้ break ออกจากลูป ถ้าไม่ใช่ให้ตัดปีกกาและเครื่องหมายคำพูดออกด้วย strip และ replace แล้วแยกชื่อกับบทบาทด้วย split(":") จากนั้นเก็บลง player โดยให้ชื่อเป็น key ส่วนบทบาทเป็น value ต่อมาใช้ while เพื่อรับชื่อผู้ที่ถูกโหวตออก ถ้าเจอคำว่า "End" ให้ break ออกจากลูป ถ้าไม่ใช่ให้ใช้ pop ดึงชื่อนั้นออกจาก player แล้วเก็บชื่อลงใน out พร้อมบทบาท จากนั้นนับจำนวน Impostor ที่เหลืออยู่โดยแปลง value ของ player ให้เป็น list แล้วใช้ count("Impostor") แล้วพิมพ์ตามด้วย "Impostor Remains" หลังจากนั้นพิมพ์ "***Alive***" แล้วใช้ for loop วนพิมพ์ชื่อและบทบาทของคนที่อยู่ใน player โดยเรียงตามชื่อด้วย sorted แล้วพิมพ์ "***Dead***" และใช้ for loop วนพิมพ์ชื่อและบทบาทของคนใน out โดยเรียงตามชื่อด้วย sorted
```

## 5. การทดสอบของฉัน

ถ้า input หรือ output มีหลายบรรทัด ให้เขียนไว้ใน text blocks

```text

***Dead***
```



## 6. การใช้ AI

ใช้ AI กับโจทย์นี้หรือไม่

```text
No
```

ถ้าใช้ AI ต้องทำไฟล์นี้ด้วย:

```text
ai_reflection.md
```

ถ้าถามเฉพาะเพื่อน TA หรือผู้สอน และไม่ได้ใช้ AI ไม่ต้องทำ `ai_reflection.md`

## 7. ความช่วยเหลือจากคน / การร่วมมือ

ได้ถามเพื่อน TA ผู้สอน หรือบุคคลอื่นเพื่อขอความช่วยเหลือในโจทย์นี้หรือไม่

```text
No
```

ถ้าใช่ ให้อธิบายสั้น ๆ ว่าได้รับความช่วยเหลือแบบใด

ตัวอย่างที่อนุญาต:

- อธิบายความหมายของโจทย์
- อธิบาย concept การเขียนโปรแกรม
- ให้ hint เกี่ยวกับแนวทาง
- คุยเรื่อง debugging
- คุยเรื่อง test cases
- ช่วยอธิบาย error message

สิ่งที่ไม่อนุญาต:

- คัดลอก code ของผู้อื่น
- ส่ง solution ของผู้อื่น
- ขอให้ผู้อื่นเขียน solution ให้
- ใช้ OJ submission ของผู้อื่น
- ขอให้ผู้อื่นส่ง OJ แทน
